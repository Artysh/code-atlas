# Changelog

## [0.1.0] - 2026-03-12

### Added
- Initial release
- AST-based TypeScript/JavaScript code analysis
- Dependency graph, call graph, component tree, route map, and architecture map views
- Interactive Cytoscape.js graph with zoom, pan, drag, and click-to-open
- Search, filter, minimap, and focus mode
- Architectural insights: circular dependencies, high coupling, orphaned files, hotspots
- Export to PNG, SVG, and JSON
- Incremental caching with file watcher
- VS Code theme-aware UI
